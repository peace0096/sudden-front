# Sudden Front

웹 브라우저에서 즐기는 1인칭 5대5 팀 데스매치. 서버는 Rust + Bevy ECS, 클라이언트는 TypeScript + three.js, 통신은 WebSocket 위의 Protobuf3입니다.

## 실행

```powershell
cd client; npm install; npm run build
cd ..\server; cargo run --release
```

브라우저에서 http://localhost:8080 을 엽니다. 같은 네트워크의 다른 PC는 `http://<서버 IP>:8080` 으로 접속합니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

클라이언트 개발 시에는 서버를 켠 채 `cd client; npm run dev` 후 http://localhost:5173 을 사용합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| W A S D | 이동 |
| 마우스 | 조준 |
| 마우스 왼쪽 | 공격 (발사 / 나이프 휘두르기) |
| 마우스 오른쪽 | 스코프 켜기/끄기 (저격소총) |

| 1 / 2 / 3 | 주무기 / 권총 / 나이프 (증강 카드 선택 중에는 카드 선택) |
| B | 주무기 선택 |
| Tab | 점수판 |
| Esc | 마우스 해제 / 방 나가기 메뉴 |

## 게임 규칙

- 방장이 대기실에서 고른 목표 킬 수(10/20/30/50, 기본 30)를 먼저 달성한 팀이 승리합니다. 팀당 5명, 방 최대 10명입니다.
- 사망 3초 후 탄약이 가득 찬 상태로 재투입되며 3초간 보호됩니다. 먼저 발사하면 보호가 풀립니다.
- 아군 사격은 없습니다.
- 맵: 보급창고(야외), 웨어하우스(실내 컨테이너 창고). 방을 만들 때 고릅니다.
- 총기는 대기실 또는 게임 중 B키로 고릅니다. 재투입 보호 중에는 즉시, 그 외에는 다음 재투입 때 적용됩니다.

| 총기 | 탄약 | 머리/몸통/다리 | RPM | 이동속도 | 장전 | 정지 시 탄퍼짐 (rad) |
| --- | --- | --- | --- | --- | --- | --- |
| 소총 K-RIFLE | 30/120 | 100/34/25 | 600 | 5.2 | 2.2초 | 0.002 |
| 저격소총 SR-7 | 5/20 | 200/100/70 | 볼트 1.3초 | 4.7 | 3.0초 | 0.009, 스코프 0.0002 |
| 기관총 MG-60 | 100/200 | 100/40/30 | 1000 | 3.7 | 4.5초 | 0.018 |
| 기관단총 SMG-9 | 25/125 | 72/24/18 | 800 | 6.3 | 1.8초 | 0.0015 |
| 권총 PT-9 (공통) | 12/36 | 70/22/16 | 240 | 5.6 | 1.5초 | 0.0012 |
| 나이프 (공통) | - | 100/60/45 | 휘두르기 0.55초 | 6.0 | - | 사거리 2.2m |

무기를 바꾸면 0.35초의 꺼내는 시간이 있고, 진행 중인 장전은 취소됩니다. 탄약은 무기별로 유지됩니다.

수치는 `server/src/game/weapons.rs` 한 곳에서 바꿀 수 있습니다.
- 방을 만들면 로비의 모든 사용자에게 목록으로 보이고, 방장이 시작을 누르면 시작합니다.
- 방 생성 시 "빈 자리는 봇으로 채우기"를 켜면 부족한 인원을 봇이 채웁니다. 게임 중에 나간 사람의 자리도 봇이 이어받습니다. 끄면 양 팀에 최소 1명씩 있어야 시작할 수 있습니다.

## 구조

```
proto/game.proto          패킷 정의의 단일 원본 (Rust, TS 코드 생성)
server/src/net.rs         WebSocket <-> 허브 스레드
server/src/hub.rs         로비, 방, 30Hz 틱 루프
server/src/game/          방마다 하나의 Bevy ECS World
  systems.rs              입력 → 무기 → 사격 → 부활 순서의 규칙 시스템
  weapons.rs              총기 스탯 표
  bot.rs                  봇 AI (사람과 같은 InputCmd 큐로 입력)
  map.rs                  맵 데이터 (점대칭 생성, MatchStart로 클라이언트에 전송)
client/src/game/          렌더링, 예측, HUD, 사운드 (에셋 파일 없이 전부 절차적 생성)
```

서버가 모든 판정을 결정합니다. 클라이언트는 이동을 예측한 뒤 서버 상태로 보정하고(`movement.ts`는 서버의 `step_move`와 동일해야 합니다), 서버는 사격 시 클라이언트가 보던 시점으로 표적 위치를 되돌려 판정합니다(lag compensation).

## 테스트

```powershell
cd server; cargo test --release          # 게임 규칙
# 서버 실행 후 (Microsoft Edge 필요)
cd client
node e2e/play.mjs                        # 브라우저 2개로 로비~전투 흐름
node e2e/kill-target.mjs                 # 방장의 목표 킬 수 선택과 실제 경기 반영
node e2e/full-match.mjs                  # 목표 킬 종료~대기실 복귀~재시작
```

## 게임 모드

방을 만들 때 고릅니다.

- **일반모드**: HP 100, 시작 대기 없음.
- **증강모드**: HP 150. 시작하면 15초 안에 카드 3장 중 하나를 고르며 그 판 동안 유지됩니다. 카드마다 아래의 변경 버튼으로 한 번씩 바꿀 수 있고, 이미 나온 증강은 다시 나오지 않습니다. 고르지 않으면 무작위로 정해지고 봇도 무작위로 고릅니다. 모두 고르면 곧바로 5초 대기 후 전투가 시작됩니다.

| 등급 (확률) | 증강 |
|---|---|
| 실버 (40%) | 무한 장전, 영혼 흡수, 권총 업그레이드, 빠른 준비, 방탄조끼, 테이저건 |
| 골드 (35%) | 샷건, 때로는 휴식이, 방패병, 작은 머리, 빙의, 대두 바이러스, 매그넘 리볼버, 더블 타임 |
| 프리즘 (25%) | 투과, 무반동, 빌려쓰기, 미사일 런처, 우지 아킴보 |
