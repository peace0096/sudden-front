# 증강모드

방을 만들 때 모드를 고릅니다. 증강모드는 HP 150으로 시작하고, 경기 시작 시 증강 카드 하나를 골라 그 판 동안 유지합니다. 팀 데스매치와 개인전 모두에서 고를 수 있습니다. 증강 규칙은 팀을 보지 않고, 개인전에서는 나를 뺀 모두가 적이라 투과(Wallhack)가 다른 플레이어 모두를 비춥니다.

규칙은 서버(`server/src/game/augments.rs`, `mod.rs`, `systems/`, `weapons.rs`), 카드 문구는 클라이언트(`client/src/augments.ts`)에 있습니다.

경기 중에 도중 참가한 사람은 카드 선택(15초) 중이면 카드 3장을 받아 남은 시간 안에 고르고(안 고르면 무작위), 선택이 끝난 뒤(5초 대기 포함)에 들어오면 받은 패에서 바로 무작위로 정해집니다.

## 진행 흐름

1. **선택 단계 (15초, `AUGMENT_PICK`)**: 플레이어마다 카드 3장이 주어집니다. 1/2/3 키나 클릭으로 고릅니다.
   - 카드마다 아래의 변경 버튼으로 그 카드만 한 번 바꿀 수 있습니다(`RefreshAugments{slot}`).
   - 한 사람에게 이미 나온 증강은 다시 나오지 않습니다.
   - 시간 안에 고르지 않으면 무작위로 정해지고, 봇도 무작위로 고릅니다.
   - 모두 고르면 선택 단계가 바로 끝납니다.
2. **대기 단계 (5초, `AUGMENT_WAIT`)**: 카운트다운. 움직일 수 없습니다.
3. **전투**: 경기 시계(`clock`)가 0부터 흐릅니다. 증강은 부활해도 유지됩니다.

대기 중에는 ECS 스케줄을 돌리지 않고 `freeze_tick`만 진행하며, 지나간 틱 수(`frozen_ticks`)는 경기 시계에서 뺍니다.

## 카드 배분

- 카드 한 장마다 등급을 먼저 뽑고 그 등급 풀에서 하나를 뽑습니다: **실버 40% / 골드 35% / 프리즘 25%**.
- 한 손(3장) 안에서는 중복되지 않습니다.

## 증강 목록

### 실버 (40%)

| 증강 | 효과 |
| --- | --- |
| 무한 장전 | 예비 탄약이 줄지 않음 (수류탄은 목숨당 1개 그대로) |
| 영혼 흡수 | 처치할 때마다 HP 50 회복 (최대 HP까지) |
| 권총 업그레이드 | 2번 무기가 PT-9+: 대미지 100/32/24, 3점사, 탄약 12/120, 위로 튀는 반동 없음 |
| 빠른 준비 | 장전 시간 50% |
| 방탄조끼 | 최대 HP 200 |
| 테이저건 | 2번 무기가 테이저: 대미지 0, 맞은 적 5초 마비(이동·사격·장전·무기 전환 불가, 시점은 자유). 탄약 1/6, 발사 간격 0.5초. 맞은 캐릭터에 전기 스파크, 화면에 마비 오버레이 |

### 골드 (35%)

| 증강 | 효과 |
| --- | --- |
| 샷건 | 2번 무기가 SG-12 펌프 샷건 (6펠릿, 한 발씩 장전, 장전 중 사격 가능) |
| 때로는 휴식이 | 마지막 전투 후 4초가 지나고 앉아 있으면 초당 15씩 최대 HP까지 회복 |
| 방패병 | 2번 무기(권총)를 들고 있을 때만 HP 1200의 방패가 앞에 생김. 수리 없음, 부활 시 새 방패 |

| 대두 바이러스 | 처치에 기여한 적의 머리 크기가 25%씩 커짐(합연산 누적, 최대 3배. `BIG_HEAD_STEP`·`BIG_HEAD_MAX`) |

| 더블 타임 | 무작위 증강 2개를 얻음 (아래 규칙) |

| --- | --- |

| 무반동 | 반동과 탄퍼짐이 모두 사라짐(샷건 펠릿 퍼짐 제외). 대신 장전 시간 2배 |
| 빌려쓰기 | 장전 모션 없이 즉시 장전 |
| 미사일 런처 | 1번 무기가 ML-9: 연속 발사 미사일, 탄약 9/36, 발사 간격 0.3초 |
| 우지 아킴보 | 기관단총을 고르면 양손에 듦: 장탄수와 연사력 2배 (B키로 기관단총 선택) |

## 더블 타임

- 고른 카드는 `Perks.augment`에 더블 타임으로 남고, 실제 효과는 `Perks.active`에 뽑힌 2개가 들어갑니다. 판정은 모두 `Perks::has()`가 `active`를 봅니다.
- 더블 타임 자신은 다시 뽑히지 않습니다.
- 같은 무기 칸을 바꾸는 증강은 함께 나오지 않습니다.
  - 1번 칸: 미사일 런처, 우지 아킴보, 빙의
  - 2번 칸: 샷건, 매그넘, 권총 업그레이드, 방패병, 테이저건
- HUD 증강 배지에 뽑힌 두 증강이 함께 표시됩니다.

## 증강에 따른 무기 지급

`weapons.rs`:
- `sidearm_for(active)`: 샷건 > 매그넘 > 테이저 > 권총 업그레이드 > 기본 권총 순으로 2번 무기 결정
- `primary_for(kind, active)`: 우지 아킴보이면 기관단총 → AKIMBO_SMG
- 미사일 런처는 고른 주무기와 상관없이 1번 무기를 ML-9로 고정(`forced_primary`)
- `base_primary`: 빙의로 주무기를 빼앗을 때 아킴보는 일반 기관단총으로 넘어감

## 미사일

- 서버 리소스 `Missiles { next_id, live }`에 투사체를 두고 `fly_missiles`가 매 틱 이동시킵니다.
- 속도 60m/s, 수명 3초. 벽에 닿거나 적 히트박스(여유 0.8m, `MISSILE_HIT_PAD`)에 닿으면 폭발합니다.
- 폭발 `blast`: 반경 3.5m, 중심 150에서 반경 끝 30%(45)까지 거리에 비례해 감소(`SPLASH_FALLOFF` 0.7), 폭발 지점에서 몸통까지 벽으로 막힌 대상은 피해 없음, 방패가 사이에 있으면 방패가 받음. 아군 피해와 자기 피해 없음(개인전에서는 쏜 사람만 빼고 모두 맞음).
- 스냅샷 `missiles`로 위치와 속도를 보내면 클라이언트가 외삽해서 그리고, `ExplosionEvent`로 폭발 이펙트·사운드를 냅니다.

## 방패

- 방패병이 보조무기를 들고 있을 때 앞쪽 판(폭 0.9m, 몸에서 0.55~0.65m, 높이 1.75m까지)에 맞은 탄은 방패 HP를 깎습니다(`DamageEvent.shield`).
- 방패 HP가 0이 되면 사라지고 부활할 때 1200으로 다시 생깁니다.
